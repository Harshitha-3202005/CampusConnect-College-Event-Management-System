# CampusConnect — College Event Management System

A colourful, responsive college event management web app built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard showing total events, upcoming events, and personal registrations.
- Add, edit, delete, search, and filter events.
- Register for events and cancel registrations.
- Event category, date, time, venue, organiser, and description.
- Saves events, registrations, and dark-mode preference in browser `localStorage`.
- Responsive layout and dark mode.
- Starter demo events for first-time use.

## Technologies
- HTML5 — structure and forms
- CSS3 — responsive layout and styling
- Vanilla JavaScript — app logic and validation
- `localStorage` — browser-based persistence

> This is a front-end project. Data is saved only in the same browser on the same device; there is no server, shared database, or user authentication.

## Run the project
1. Extract the ZIP file.
2. Open the `CampusConnect-College-Event-Management` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the Live Server extension in VS Code, right-click `index.html`, and select **Open with Live Server**.
4. Try adding an event, registering, searching/filtering, editing/deleting, and refreshing to verify the data persists.

## Project files
- `index.html` — page layout and event form
- `style.css` — responsive colourful interface
- `script.js` — event management, registrations, filters, theme, and local storage
